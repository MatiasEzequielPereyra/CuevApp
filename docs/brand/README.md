# Marca de CUEVA

[reference.jpeg](reference.jpeg) es la captura original íntegra. Se conserva aquí
como fuente documental y nunca se sirve desde `public/`. El hash y la procedencia
están en el [manifest](../engineering/source-manifest.json).

El [símbolo de aplicación](../../public/brand/cueva-symbol.svg) contiene únicamente
círculo negro y contornos blancos. No utiliza una fuente para escribir la marca,
ni incluye barra del teléfono, fondo de la captura o botones de la red social.

Se trazaron manualmente formas geométricas tomando como referencia aproximada
la región x=166..568, y=753..827 del JPEG de 720×1600. El círculo corresponde
aproximadamente a x=122..598, y=563..1038. La comparación no afirma igualdad de
píxeles ni disponibilidad del archivo maestro: es una **reconstrucción provisional**.

Abrir [comparación lado a lado](../../evidence/logo-comparison.html). La ventana
CSS limita la referencia al símbolo sin modificar el original. La evidencia
renderizada está en [comparación verificada](../../evidence/screenshots/logo-comparison.png).

Revisar la C cuadrada abierta, U rectilínea, E con barra central separada, V
angular y A sin travesaño; mantener proporciones, espacios, trazos y silueta.
El SVG tiene título, y su componente proporciona `alt` salvo uso decorativo.
La marca permanece blanca sobre negro en ambos temas.

La tipografía del texto de interfaz usa la pila del sistema disponible (Arial,
Helvetica, sans-serif); no se descarga una fuente externa. La aplicación no
presenta esa tipografía como el lettering oficial.
